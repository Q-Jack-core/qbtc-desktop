Self-Custody Key Isolation

Q-BTC Desktop runs a local full-node verifier and ML-DSA-65 encrypted keystore. Built-in pool mining has been removed to keep private keys isolated from external mining environments. Generate your qbtc1... address in Wallet Overview and mine directly to your own receiving address.

1. Community Pool Mining (CPU / GPU)

Connect to any independent community-operated Stratum pool using open-source CPU, CUDA, or OpenCL miners shared in the QBTC Genesis Members community. Never use a pool as long-term storage.

2. Local Solo Mining (Core CLI)

To solo mine directly against a local full node without a pool, run Q-BTC Core CLI and execute: auto_mine start <wallet_alias_or_address>
